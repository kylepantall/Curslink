# Handover: the missing illustrations

Kyle's feedback on 0.4.14 was "there's no illustrations". This brief covers what's missing and where each piece goes. It's written so another coding agent can pick it up from the repository alone.

## Background

Curslink is a PySide6 desktop app (`curslink/gui/`) with Windows 11, macOS and GNOME looks, in light and dark. The design spec is `docs/design/desktop-ui-spec.md`. Read section 5, "Illustrations and icons", before starting:

- **Spot illustrations:** `curslink/assets/illustrations/spot/<name>.svg`, generated by `packaging/illustrations/make_spot.py`. Each is 160 × 120 on a transparent background in the brand palette, so one file works in light and dark. The style rules are in section 5.4: slate `#7A8BA6` 2 px outlines with round caps, slate fills at 16%, an active screen with a `#B6DFFF` to `#3FA9FF` gradient, 22 px status badges, and dashes of 5 on, 5 off.
- **Helpers:** `curslink/gui/widgets.py` has `spot(name, w, h)`, `set_spot(label, name, w, h)` and `EmptyState(art, title, text="", action=None, size=(160, 120))`.
- **Reference art for the live widgets:** `curslink/assets/illustrations/<platform>-<theme>/`, which holds `screen-mini-map.svg`, `layout-canvas.svg` and `pairing-code-card.svg`.

0.4.16 already fixed two things: a gap at the top of every card, and the host Status card showing an empty map instead of `not-linking`. Don't redo them.

## The work

### 1. Use the illustrations that exist but aren't shown

| Art | Where it goes (spec 5.4) | Today |
|---|---|---|
| `diagnostics` | Settings, Diagnostics card, after a crash (`diagnostics.last_native_crash()` isn't None): 96 × 72 beside "Curslink closed unexpectedly" and the Save diagnostics button | Not used |

### 2. Give the text-only empty states a picture

These cards show a single grey sentence today. Use an `EmptyState` at 120 × 90 (or 96 × 72 if the card is short):

| Card | Art | Title / line |
|---|---|---|
| Status, Recent switches (nothing yet) | new `no-switches`: two screens with a dashed pointer arc and no pointer | "No switches yet" / "Switches show up here as they happen." |
| Status, Activity (empty log) | reuse `searching` or a new `quiet-log` | "Nothing to show yet" |

Draw any new art by adding a function to `packaging/illustrations/make_spot.py` in the same style, then regenerate. Don't hand-edit the generated SVGs.

### 3. Make the live screen maps look like their reference art

`curslink/gui/screenmap.py` (`ScreenMap`) draws the Status mini map, the Calibrate map and the Layout canvas. It draws plain grey rounded rectangles. Kyle compared it with the mockup and called it "plain grey outlines". Match `screen-mini-map.svg` and `layout-canvas.svg` for the current platform and theme:

- Draw a monitor stand under each screen (the neck and foot from the SVG). Draw a laptop base for agent screens whose device is a laptop, if that's known; otherwise use a stand.
- Inactive screens get the 16% neutral fill and the slate outline.
- The active screen gets the sky gradient fill, an accent outline, and the soft outer ring. The pulsing dot pulses every 2.4 s, with no pulse when reduced motion is requested.
- The looking screen keeps its current marker.
- Keep the data the widget draws. Only the look changes.

### 4. Check it

- Run `python -m pytest -q`. All tests must pass, and add tests where you add behaviour (for example, that the Layout empty state shows with one device).
- Render each page offscreen in all six looks before and after, and compare them with the mockup (`QT_QPA_PLATFORM=offscreen`, with `CURSLINK_LOOK=win|mac|linux`, `CURSLINK_DARK=1` and `CURSLINK_NO_EFFECTS=1`). `tests/test_gui.py` shows how to build the window.
- Don't change the version number and don't start a release. Open one PR against `main` and list each place that now has art.
